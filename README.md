## 📚 Tentang Project

**Japan N5 v10** adalah aplikasi pembelajaran Bahasa Jepang tingkat
**JLPT N5** yang dibuat untuk membantu pemula belajar secara lebih
mudah, interaktif, dan menyenangkan.

Aplikasi ini dapat digunakan untuk mempelajari Kanji dan Kotoba serta
melatih kemampuan melalui soal-soal interaktif.

---

## ✨ Fitur

- 🇯🇵 **Kanji N5**
- 📖 **Kotoba / Kosakata N5**
- 📝 **Latihan Pilihan Ganda**
- 🎯 **Quiz Interaktif**
- 📊 **Sistem Skor**
- 📱 **Responsive untuk Smartphone**
- 💻 **Dapat digunakan di PC/Laptop**
- ⚡ **Ringan dan cepat**
- 🌐 **Berjalan langsung di Browser**

---

## 🎓 Materi Pembelajaran

Materi yang tersedia berfokus pada Bahasa Jepang tingkat dasar:

- Hiragana
- Katakana
- Kanji N5
- Kotoba N5
- Arti kosakata
- Cara membaca Kanji
- Latihan Kanji → Hiragana
- Latihan pilihan ganda
